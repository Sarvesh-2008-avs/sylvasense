# Sylvasense 🌳
### AI-Powered Forest Intelligence and Monitoring Platform

## 📌 About the Project
Sylvasense is a forest monitoring platform designed to analyze vegetation using satellite imagery and AI-based tree detection. It helps users understand vegetation conditions and explore forest monitoring data through a web interface.

## 🎯 Objectives
- Monitor vegetation using satellite imagery.
- Analyze vegetation health using NDVI.
- Display forest analysis results on an interactive map.
- Detect tree crowns using AI-based computer vision.
- Support forest monitoring and environmental analysis.

## ✨ Key Features
- **NDVI Analysis:** Analyze vegetation signals from Sentinel-2 satellite imagery.
- **Interactive Map:** Select an area of interest for forest analysis.
- **Vegetation Statistics:** Display vegetation coverage and NDVI results.
- **Tree Detection:** Use a YOLO-based model for tree detection.
- **Web Dashboard:** View forest analysis results through a user-friendly interface.

## 🛠️ Technologies Used
- Frontend: React, Vite, React-Leaflet
- Backend: Python, FastAPI
- Satellite Data: Google Earth Engine, Sentinel-2
- AI / Computer Vision: YOLOv8
- Mapping: Leaflet

## ⚙️ Project Workflow
1. Select an area of interest on the map.
2. Retrieve suitable satellite imagery.
3. Process imagery and calculate NDVI.
4. Analyze vegetation statistics.
5. Run tree detection where applicable.
6. Display results on the dashboard.

## 🚀 Getting Started
### Prerequisites
- Python
- Node.js and npm
- Google Earth Engine access and authentication, if required by the backend

### Installation
1. Clone this repository.
2. Install the frontend dependencies.
3. Install the backend dependencies.
4. Configure the required environment variables and Earth Engine authentication.
5. Start the backend and frontend servers.

Refer to the project files for the exact installation commands and configuration.
